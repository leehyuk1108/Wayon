## Corrections and Limits

Initial Web Push failed before network transmission because workerd does not
support `redirect: 'error'`. Actual-runtime tests reproduced this and verified
`manual`, with redirects treated as failures rather than followed. Do not equate
provider acceptance alone with physical notification display; this test also has
the user's lock-screen confirmation.

An original hidden settings target was made visible with a small settings icon
in its existing position, only in the PWA. No Android visual redesign was made.

Testing exposed a session-revocation race while the engine-start preflight marker
was pending. Recheck the exact session/account after all awaited preflight work
and lease renewal, immediately before dispatch. Tests cover logout and account
replacement. All command tests remain simulated; production controls stay off
until owner UUID/VIN are independently verified and pinned.

No physical vehicle commands, road tests, actual iPhone live-video checks or
long-duration delivery guarantees are claimed. Native-only Android functions do
not become available merely by installing the web app.
